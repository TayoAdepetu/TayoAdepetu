# Technical Mentorship — Fair Usage Policy

**Applies to:** LaunchWithCursor Founder Launch membership (12 months).

---

## What mentorship is

**Advisory guidance** to help you build and ship your own MVP with Cursor. We help you think, debug, and unblock — we do not build features for you.

---

## What is included

### 1. Unlimited asynchronous support

Channels: WhatsApp, Slack, email, or Discord (as configured for your cohort).

**Good for:**

- Quick questions ("What should I tell Cursor?")
- Deploy error interpretation
- Architecture sanity checks
- Prompt wording help
- "Is this normal?" reassurance

**Response target:** Within 24 hours on business days.

### 2. Scheduled deep-dive sessions

- **Duration:** 30–60 minutes
- **Book in advance**
- **Use for:** debugging, deployment issues, planning, code review, security questions

**Fair usage:** Approximately 8–12 sessions per year per member. Heavy usage may be scheduled further apart.

### 3. One active request at a time

Finish or close one thread before opening a large new topic. Keeps context clear for both sides.

---

## What is NOT included

- Writing your product features for you
- Unlimited live coding sessions
- Native mobile app development (App Store / Play Store)
- Marketing, sales, or legal advice
- 24/7 on-call production support
- Guaranteed uptime SLAs (see platform terms)
- **Paid manual software testing** — hire testers from the LaunchWithCursor QA marketplace (project → QA / Testers). That is a separate product from mentorship hours.

---

## Session types (deep-dives)

| Type | Examples |
| ---- | -------- |
| Architecture review | Scope, monorepo shape, database design |
| Debugging | Production errors, failed deploys |
| Deployment | Manifest, env vars, migrations |
| AI prompting | Cursor workflow, phase plans |
| Code review | Security, structure, performance |
| Technical planning | What to build next after launch |

---

## How to get the most value

1. Try the fix-pass prompt in [02-cursor-mastery.md](../METHOD/02-cursor-mastery.md) first
2. Paste **exact error logs** and **what you expected**
3. Book a live session when stuck > 2 hours on the same issue
4. Come to sessions with repo access and dashboard open

---

## Priority

Members who are actively building (commits in the last 14 days) receive priority for scheduled sessions.
