# Agent instructions — LaunchWithCursor founder projects

Before planning or writing code on a founder MVP project:

1. Read [README.md](README.md) for guide order
2. Apply [SKILLS/FRONTEND.md](SKILLS/FRONTEND.md) for all UI work
3. Apply [SKILLS/PWA.md](SKILLS/PWA.md) for customer-facing mobile (PWA, not native)
4. Apply [SKILLS/BACKEND.md](SKILLS/BACKEND.md) for NestJS/API work
5. Apply [SKILLS/Infrastructure.md](SKILLS/Infrastructure.md) from Phase 1 for deploy/env/manifest

Default stack: React or Next.js + NestJS + Postgres. Mobile = PWA only for MVP.

Deploy manifest: `launchwithcursor.deploy.json` at repo root.
